## About

**OptiTool** is a lightweight, `.cmd`-based utility for optimizing and managing Windows systems. It provides a simple menu-driven interface with no installation dependencies beyond the script itself.

### Features

- System optimization
- Display detailed system information
- Uninstall applications
- And more

## Installation

1. Download the `.zip` file from the link above.
2. Extract the contents to a folder of your choice.
3. Open the extracted **OptiTool** folder.
4. Run `Launcher.cmd`.
5. That's it — the tool is ready to use.

---

## Usage

OptiTool runs entirely from a simple `.cmd` interface. Each button in the menu corresponds to a specific function, and built-in guides walk you through each feature so you can use the tool without prior experience.

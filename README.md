## Installation

### Installation via .zip

1. Download the file using the provided link.
2. Extract the contents to a folder of your choice.
3. Go to the **OptiTool** folder.
4. Run `Launcher.cmd`.
5. Enjoy the tool!

## Usage

The tool has a simple interface, as it is made in `.cmd`. Each button has its respective function, and the script includes guides to help you use it without difficulty.

The features of **OptiTool** include:
- System optimization.
- Displaying system information.
- Uninstalling applications.
- And more...

This idea came from a tool called [OptiJuegos](https://optijuegos.net) called Optimizar PC. The code for the OptiTool foundations comes from this tool. I will never forget the origin of this idea, thanks to [OptiJuegos](https://linktr.ee/optijuegos)!

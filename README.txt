====================================
            OptiTool
====================================

OptiTool is a simple batch script for applying optimizations to your
low-end/budget gaming PC

------------------------------------
How to run
------------------------------------
Run Launcher.cmd in the root folder. It will request administrator
privileges and then start the main tool

------------------------------------
Additional optimizations
------------------------------------
You can apply MORE optimizations using the extra files found in the
Appearance, Graphics, RAM and Resources (inside of Assets) folders. They're very simple
to apply: just open the .reg or .bat file and you're done

Do not delete any resource from the program's root or
optimization folders, since they are required for the optimizations
to be applied without issues.
